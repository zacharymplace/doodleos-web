## Sheet Format

- 8.5 x 11 inches
- White or off-white background
- 0.25 inch safe margin
- At least 0.15 inch spacing between stickers
- Keep text readable at final print size

## Layout Recommendation

Top row:
- Recall Remains In Beta
- Personal Space Deprecated

Middle row:
- Wet Beige Missile
- Sock Hostage Protocol

Bottom row:
- Doorbell Processor Unstable
- Love Kernel OK

## Cricut Notes

- Use simple rounded rectangle or outline cuts where possible
- Avoid complex contour cuts for first test
- Print one test sheet before batch production
- Confirm dark borders do not get trimmed too tightly

## QA

- [ ] All sticker text is readable
- [ ] Borders print cleanly
- [ ] Cut paths do not clip artwork
- [ ] Colors remain muted and system-like
- [ ] Sheet feels DoodleOS, not generic dog merch
