# DoodleOS Sticker Pack 001

## Name

System Instability

## Purpose

First physical DoodleOS merch drop. The pack should feel like legacy computer labels, warning stickers, and system diagnostics escaped into golden doodle ownership.

## Format

- Sticker pack
- 6 primary stickers
- 2 bonus micro-labels
- Designed for Canva sheet assembly
- Cricut-friendly shapes
- High contrast
- Minimal fine detail

## Print Notes

- Prefer off-white/beige base
- Use slate/black borders
- Use muted blue, amber, green, and red as status colors
- Avoid paw-print filler
- Avoid generic cartoon dog art
- Keep text readable at sticker size
