# DoodleOS Brand Assets

## Core Identity

DoodleOS is fake legacy companion software for diagnosing golden doodle chaos.

## Visual Rules

- Use DoodleOS as the public brand
- Use DoodleOS 95 Mode as the interface mode
- Prefer beige, slate, muted blue, amber, and old-system neutrals
- Prefer hard borders, window panels, status badges, and dry labels
- Avoid generic cute dog branding
- Avoid cluttered nostalgia
- Avoid excessive paw prints

## Asset Priorities

1. Favicon
2. App icon
3. Improved Open Graph image
4. Small 95-style utility icons
5. Optional sticker/merch graphics later
