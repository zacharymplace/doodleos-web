# DoodleOS v0.1

Public-share prototype for DoodleOS.

## Live URL

https://doodleos-web.vercel.app

## Included

- DoodleOS 95 Mode visual system
- Homepage diagnostic funnel
- Interactive doodle report generator
- Interactive incident report generator
- Copy/share report text
- Status page
- Patch notes
- Error codes
- Incident archive
- Fake pricing page
- Desktop Start Bar
- 95-style cursor accent

## Validation

```bash
npm run lint
npm run build
vercel --prod
```

## Positioning

DoodleOS is legacy companion software for diagnosing golden doodle chaos.

Primary joke:
A dead-serious obsolete enterprise system is trying to govern golden doodle instability.
