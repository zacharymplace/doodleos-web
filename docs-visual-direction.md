# DoodleNet 95 Visual Direction

DoodleOS should move toward a fake 1995 internet/intranet control panel for golden doodle infrastructure.

## Direction

Working name: DoodleNet 95

The interface should feel like:
- Windows 95 utility software
- early internet pet database
- municipal intranet
- fake enterprise control panel
- beige family-computer chaos

## Visual Ingredients

- off-white, beige, slate, muted blue
- hard borders mixed with modern spacing
- fake window chrome
- status lights
- mono labels
- diagnostic panels
- alert banners
- pixel-ish icons where tasteful
- “system folder” navigation language

## Avoid

- generic cute dog blog
- modern bubbly pet startup
- excessive paw prints
- cartoon overload
- unreadable retro styling

## Brand Feel

DoodleNet 95 is not nostalgic for nostalgia’s sake.

It should feel like an ancient government computer system was accidentally assigned to manage the emotional instability of golden doodles.
